# Welcome!

This is a core platform project in the [Federated PWA](https://fnalabs.com/federation) pattern used to rebuild our existing PWA, [FnA Labs](https://fnalabs.com). The pattern extends a blend of React Components to build a base library of Bulma CSS framework experiences and custom Templates and Layouts leveraging those atomic building blocks. It is our interpretation based on Bulma's documentation but we think we captured much of the functionality.

The use cases for this project are:

- Leverage [Module Federation](https://module-federation.io/) to share common UI experience components.
- Use [Bulma](https://bulma.io/) CSS framework to provide a consistent look and feel across all apps.
- Built specifically for all UI projects under the FnA Labs umbrella.

## INFOs

This section provides details on how to use this project from the perspective of the heading topics below.

### Consume in federated UI apps

This project is built on the latest version of Module Federation and is designed to be consumed by other federated UI apps. To consume this project, please follow the steps below:

```ts
import { registerRemotes } from '@module-federation/enhanced/runtime'

// NOTE: depending on your Module Federation setup, there may be additional commands
registerRemotes([
  {
    name: 'fnalabs_assets',
    entry: 'https://fnalabs.github.io/fnalabs-assets/assets/mf-manifest.json',
  },
  // NOTE: include other remotes as needed
])
```

### Contribute

To contribute to this project, please follow the steps below:

1. Ensure you have the following dependencies installed on your local machine:

   - latest [Node.js LTS](https://nodejs.org/en/download) (v24 or higher)
   - NPM (whatever comes with Node.js LTS above)
   - internet connection to access global styles

2. Install project dependencies with `npm ci`.
3. Run the project with the following commands:

   - `npm run build` - builds the project for production.
   - `npm run build:storybook` - builds Storybook for production.

     ***NOTE:*** When contributing, please be sure to build the project before submitting a pull request until our pipelines are configured.

   - `npm run build:all` - runs both build commands above in the order listed.
   - `npm run storybook` - runs Storybook for local development and testing.

     ***NOTE:*** Storybook tests can be janky at times, re-run if you get unexpected failures.

   - `npm run test` - runs all unit and integration tests with Playwright.
